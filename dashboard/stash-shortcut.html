Add to your HubFace stash from the iPhone Share button

This sets up an iPhone Shortcut. Afterwards, in Safari, YouTube or most apps, tap Share and pick Add to HubFace stash.

1. Get your stash key

Checking…

Copy this key now. It is shown only once.

Making a new key turns off the old one. Anyone with the key can add to and list your stash, so don't share it.

2. Build "Add to HubFace stash"

  1. Open the Shortcuts app and tap +. Name it Add to HubFace stash.
  2. Tap the ⓘ (details) and turn on Show in Share Sheet. Under share sheet types, keep URLs and Text (you can turn the others off).
  3. At the top, set "Receive URLs and Text from Share Sheet". If there's no input, choose Ask For Clipboard or Stop.
  4. Add the action Get Contents of URL. URL: https://hubface.org/api/stash/shortcut/add
  5. Tap Show More. Method: POST. Headers: add Authorization with value Bearer followed by your key (one space after Bearer).
  6. Request Body: JSON. Add field url (Text) and set it to the Shortcut Input variable.
  7. Add the action Show Notification with the text Saved to HubFace stash.
  8. Tap Done. Try it: in Safari, Share → scroll the app/action list → Add to HubFace stash.

3. Build "Open my stash"

  1. New shortcut, name it Open my stash.
  2. Add the action Open URLs with https://hubface.org/interface/stash.html.
  3. Optional: ⓘ → Add to Home Screen.

Good to know

  • There's no one-tap install file yet. iPhones won't import a Shortcut file that wasn't made on an iPhone or Mac. Once Dan builds it once, he can share an iCloud link, and others only need to paste their own key.
  • This shows in the general Share sheet. It does not put HubFace in the Messages + row. That needs a native iPhone app.
  • "Open my stash" opens Safari, not a Home Screen web app. Safari has its own sign-in, so you may need to sign in to HubFace there once.
  • YouTube links are saved as a link with title and channel. The video is never downloaded.
